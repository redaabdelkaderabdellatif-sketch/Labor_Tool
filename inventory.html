Search a Sales Order by Reference Number

Type part of a reference number (e.g. 6-2) and a list of every matching number from the uploaded files will appear — pick one or more (e.g. QUTO 0006-2 and Q 0006-2 together) then click Search. The search covers every uploaded file (transfers + returns + final, if provided), and groups each item into a single row with the total quantity and amount — returns are automatically subtracted (negative qty/amount) before grouping.
